# Current behavior inventory

Observed baseline: 2026-10-15. This records implementation behavior, not the desired CLI contract. Source references below point to the legacy MCP entry. All 28 tools are declared at [src/index.ts](../../src/index.ts#L133); schemas are advertisements, not uniformly enforced validation. Success/failure payloads are JSON serialized inside MCP `content[0].text`; exceptions generally become `{ok:false,error:{tool,code,message,hint?,issues?}}`, with several hand-written exceptions below.

## Shared storage and correctness constraints

- [storage.ts](../../src/storage.ts): MCP_MIDI_BASE_DIR overrides module-relative root. Data is base/data; default manifest is **manifest.PID.json** unless MCP_MIDI_MANIFEST is set. Independent processes therefore cannot normally resolve previous IDs. MCP_MIDI_MANIFEST_NOCACHE=1 disables mtime-based cache. Manifest paths can be configured outside data through absolute/path traversal values.
- Files and manifest are separate writes without atomic rename, lock, rollback, or collision checks. Corrupt/unreadable manifest silently becomes empty; a disappearing file can return cached old manifest. Shared fixed manifests can lose concurrent updates. User names are joined/resolved without confinement and are not just basenames. Multiple IDs can alias one overwritten file; byte metadata for earlier IDs becomes stale. Recording createdAt uses epoch string whereas other writers use ISO.
- [cleanMidi.ts](../../src/cleanMidi.ts#L43) keeps the first encountered tempo/time/key event of each type (track traversal, not global chronological minimum), deletes all later occurrences including real changes, and forces surviving metas to tick0. This is current behavior, not safe general normalization.
- insert_cc/insert_sustain interpret explicit 1..16 as external and 0 as legacy internal. They also run the same conversion on inferred internal track channel, so internal channel1 can shift to0. Preserve/regress this distinction deliberately; do not blindly copy ambiguity into new contracts.
- play_smf builds Ev only on/off at [L2415](../../src/index.ts#L2415). Precise bar extraction seeds CC/PB/meta into intermediate JSON, but the final schedule ignores CC/PB/program. Dry-run debug JSON therefore cannot prove controller delivery. ToneJS channel1..15 is decremented despite its usual internal0..15 convention. Native warnings may report success without sound. ms/simple clipping does not seed crossing NoteOn at range start; end NoteOff can be synthesized. Simple ranges keep absolute timestamps. Precise extraction supports tempo/signature changes but may fall back to simplified mode on errors. Note times use ToneJS tempo-aware seconds, not directApi first-tempo duration approximation.
- Continuous recording converts milliseconds at fixed120 BPM ([L1383](../../src/index.ts#L1383)); raw event filters and timeout behavior need real/fake-device validation. Autosave errors only go to stderr, saved IDs/results are discarded, and manual stop can race/repeat autosave. No persisted session state or crash recovery exists. Cleanup interval and exit listener are installed within the request handler ([L996](../../src/index.ts#L996)), causing accumulation for every request reaching that section. Cleanup removes old completed/error sessions after24h, checked every5min.
- Single-capture completion is checked by incoming events/status, not a standalone completion timer. Pitch-keyed state ignores channel and repeat identity. Stateful operations require one surviving process and do not survive CLI process exit.
